# 研究結果のまとめ（数値の一次資料）

最終更新: 2026-10-27。論文・スライド・解説資料の数値はすべてここに合わせる。

## 研究の問い

ハエの全脳配線図（FlyWire v783）から作ったスパイキングモデル（Shiu ら 2024, Nature）は、実験で確かめられた予測を出せると報告されている。
では、同じ実験を「右半球」から行っても同じ答えになるか？（＝鏡像テスト）
答えが違うなら、配線図のどんな誤りが原因か？ 誤りの種類ごとに、予測はどれくらい壊れるか？

## データとモデル

- FlyWire v783: ニューロン 138,639 個、結合 15,091,983 本、シナプス 54,492,922 個
- モデル: Shiu ら 2024 の LIF（漏れ積分発火）モデル。自由パラメータは w_syn = 0.275 mV の1つだけ
- GPU 実装（PyTorch, RTX 5070 Ti）: 1 秒の試行が約 0.2 秒
- 元の Brian 2 実装と完全一致: 3 条件でニューロンごとの発火率の相関 r = 1.000（409〜8,856 ニューロン）。MN9 は 56.7/85.8 Hz 対 56.6/85.9 Hz
- 実装上の発見: Brian 2 では、不応期中に届いたシナプス入力は捨てられる（電位の記録で確認）
- 版の違い（v630 と v783）: 左の砂糖刺激で r = 0.997（362 ニューロン）、MN9 は 67.8 → 59.8 Hz

## 6 つのベンチマーク（Shiu らが実験で確認した予測）

| ベンチマーク | 左から刺激 | 右から刺激 |
|---|---|---|
| 砂糖 GRN → MN9（口吻を伸ばす運動ニューロン） | 58 Hz ✓ | 0.4 Hz ×（暴走） |
| 苦味で抑制 | 89% 抑制 ✓ | × |
| Ir94e で抑制 | 78% 抑制 ✓ | × |
| JO（触角の機械感覚）→ aBN1（同側） | 68 Hz ✓ | 10.5 Hz × |
| JO → aDN1（反対側） | 29 Hz ✓ | 0 Hz × |
| JO → aDN2（反対側） | 33 Hz ✓ | 0 Hz × |

- 判定基準: 砂糖 MN9 > 20 Hz、抑制 > 50%、aBN1 > 20 Hz、aDN > 10 Hz。暴走 = 2,000 個超のニューロンが発火
- 刺激: 味覚 100 Hz、JO 150 Hz、各 8〜10 試行（1 秒）
- 右の砂糖刺激（100 Hz 以上）で 8,612 個のニューロンが発火（左は 412 個、21 倍）。暴走の開始は試行ごとに 59, 135, 414 ms
- Brian 2 でも右の暴走を確認（8,766 個、MN9 0.5 Hz）

## 原因 1: 右の味覚ニューロンのシナプスが少ない（入力側の再構成不足）

- 1 ニューロンあたりの出力シナプス（右/左）: 砂糖 125/265 = 0.47、苦味 0.64、Ir94e 0.73、水 0.36、JO は 1.18（欠損なし）
- 砂糖 GRN の出力シナプス総数: 左 8,700（33 個）、右 3,000（24 個）
- 左の砂糖 GRN のシナプスをランダムに抜くと、総数 5,000 未満で MN9 が急落。右と同じ 3,000 では 1〜10 Hz（右の実測 1.3 Hz と一致）
  - 削除率ごとの MN9（触角葉補正あり, 100 Hz）: 0%: 60.7, 10%: 58.6, 20%: 54.0, 30%: 50.7, 40%: 41.4, 50%: 28.6, 60%: 10.2, 70%: 0.9, 80%: 0 Hz

## 原因 2: 右の aBN1（触角掃除ニューロン）の入力が少ない（出力側の再構成不足）

- 入力シナプス: 左 1,833、右 459（0.25 倍）。JO から aBN1 への直接シナプス: 左 103、右 35

## 原因 3: 伝達物質の誤判定が暴走の入口を作る

- 暴走は、触角葉の局所ニューロン lLN2T_b/c/e（「セロトニン」と予測）を通って広がる
- 触角葉の局所ニューロンのうち「セロトニン」と予測された 40 個は、確信度の中央値 0.35（GABA 0.52 など他より低い）
- モデルはセロトニンを興奮性として扱う → 本来ブレーキ役の細胞がアクセルになる
- 触角葉に入るセロトニン細胞は、本来は片側 1 個の CSD ニューロン（局所ニューロンではない）
- この 40 個だけを抑制性にすると、右の暴走が消える（8,680 → 236 個）。左のベンチマークは変わらない
- 一律に全セロトニン予測（2,201 個）を抑制性にすると、暴走は消えるが左の苦味抑制が消える（苦味 GRN の 7/21 個がセロトニン予測のため）
- 同じ細胞タイプでも左右で予測が違う: 苦味 GRN のセロトニン予測は左 7/21、右 19/21

## 救済（補正）実験

| 右半球への補正 | 再現できたベンチマーク |
|---|---|
| 補正なし | 0/6 |
| 触角葉の符号補正（40 個） | 0/6 |
| ＋入力シナプス補正（砂糖 ×2.12、苦味 ×1.57、Ir94e ×1.38） | 3/6（砂糖 MN9 47 Hz、苦味 85% 抑制、Ir94e 93% 抑制） |
| ＋読み出し補正（aBN1 入力 ×3.99） | 4/6（aBN1 74 Hz） |

- 反対側の aDN1/aDN2 だけは回復しない（3 Hz）→ 未特定の原因が残る

## 誤りの用量反応（図 3）— 配線図にわざと誤りを入れる

左半球のベンチマーク（砂糖 MN9、苦味抑制、Ir94e 抑制、JO→aBN1）で、誤りのない配線図を 1 として比べた。各水準 3 回のランダムな誤り × 8 試行。

| 誤りの種類 | 結果 | 効果が半分になる水準 |
|---|---|---|
| シナプスの見逃し（ランダムに削除） | 20% 削除で砂糖 MN9 が半分（0.52）、30% で 0.08、40% でゼロ | 20〜45% |
| 樹状突起の切断（各ニューロンの入力を一部失う） | 似た傾向 | 20〜44% |
| 軸索の切断（各ニューロンの出力を一部失う） | 似た傾向 | 24〜44% |
| 偽のシナプス（ランダムに追加） | 80% 追加してもまったく変化なし | 到達せず |
| 符号の誤り（ランダムな細胞の興奮⇄抑制を逆に） | 1〜2% なら変化は 13% 以内。10% で苦味抑制が消え、20% で 3 回中 2 回暴走 | 8〜18% |
| 伝達物質の誤判定（AI の確信度に基づく） | 実際の誤り率に相当する 6%（細胞単位で約 94% の精度）ではベンチマークは 91% 以上残るが、3 回中 1 回暴走。12% で苦味抑制が消える | 9〜26%（JO は到達せず） |
| シナプスの強さのばらつき（平均 1 の対数正規） | σ = 0.5 まではおおむね保たれる。σ = 1 ではすべて暴走 | σ 1.4〜1.9 |

- 解析上の慣習も効く: 5 シナプス未満の結合を捨てると JO→aDN1 が 83% 減少。グルタミン酸を興奮性にすると 30,128 個が暴走し、苦味・Ir94e の抑制が逆転
- 脳全体の応答の類似度は、ベンチマークが崩れるところでもなだらかにしか下がらない（例: 40% 削除で r = 0.80）
- 解釈: モデルの唯一のパラメータ w_syn は再構成済みの配線図に合わせてあるので、脳全体に共通する欠損はある程度吸収されうる。問題は特定の回路だけの欠損。注意: 上の「20% で半減」は脳全体のシナプスを一様に消したときの値。砂糖 GRN の出力だけを消した場合（図 2b）は約 50% で半減する。右の砂糖 GRN の出力シナプスは総数で左より 66% 少ない（3,000 対 8,700）ので、この半減点を超えている
- 符号の誤りの割合と伝達物質誤判定の水準の対応: 確信度の 0.25 倍 → 6.1%、0.5 倍 → 12.2%、1 倍 → 24.3%、2 倍 → 47.0% の細胞で符号が変わる

## 131 種類の感覚ニューロンでの鏡像テスト（図 4）

- 対象: 左右それぞれに 3 個以上の注釈があるすべての感覚細胞タイプ（嗅覚 53、機械感覚 50、味覚 13、湿度 4、温度 3、視覚 3、未分類 5）。各タイプを左右別々に 100 Hz で刺激（4 試行）
- 暴走（2,000 個超）を起こしたタイプ（左右どちらかで）:
  - 公開版: 61/131（47%）。嗅覚 53 中 52
  - 触角葉の 40 個を抑制性に補正: 9/131（7%）。多くは 2,000 個ぎりぎり
  - さらに細胞タイプ単位の多数決で符号を補正: 1/131（光受容細胞 R1–6、最大の集団）
- 左右の一致度（触角葉補正後、細胞タイプ単位の応答の相関）:
  - 同じ側を 2 回（乱数だけ変える）: 中央値 r = 0.99（四分位 0.98〜1.00）
  - 左と右: 中央値 r = 0.58（四分位 0.41〜0.72）。Wilcoxon 検定 P = 2 × 10⁻²²、n = 126 タイプ
  - 126 タイプ中 93 で、左右の一致度が「同じ側の繰り返し」の最低値より低い
- 食い違いは、刺激したニューロン自身のシナプス数の左右差では説明できない（Spearman ρ = −0.06、P = 0.5）→ 下流の回路で生じている
- 嗅覚の左右の偏り: 刺激した側に残る活動の割合（中央値）は左刺激 0.53、右刺激 0.45（P = 0.002、n = 45）。右の嗅覚入力が、左の触角葉の局所ニューロンを右より強く動かす。機械感覚では偏りなし（P = 0.44）

## 結論（一文で）

配線図シミュレーションの予測は、どちらの半球で計算するかで変わる。原因は脳ではなく配線図の再構成の誤り（シナプスの見逃しと伝達物質の誤判定）で、左右の鏡像テストはそれを見つける安価な対照実験になる。

## 査読を受けた改訂（2026-10-27 03:25）— 以下が最新。上と食い違う場合はこちらを優先

### 表現の方針
- 「誤り」と断定しない。「左右の非対称性（おそらく再構成の誤り）」と書く。どちらの半球が正しいかは本当はわからない。補正は「十分性」の確認にすぎない（左を基準にしている）
- 刺激は「細胞タイプ単位」で定義した（例: 左の砂糖 GRN は LB3b と LB3c の 33 個すべて、JO は 229 個）。Shiu らが選んだニューロンの組（砂糖 21 個、JO-CE 70 個）とは違う
- 論文タイトル: Mirror-image tests reveal hemispheric asymmetries that alter whole-brain connectome simulations

### 新しい発見: 暴走の「入口」は右の砂糖ニューロン 1 個
- 右の砂糖 GRN 24 個を 1 個ずつ抜いて刺激すると、LB3b の 1 個（FlyWire 720575940629884119）を抜いたときだけ暴走が消える（8,522 → 58 個）
- このニューロンは出力 154 シナプスのうち 22 個を、触角葉の局所ニューロン il3LN6 に出している。左の LB3b（13 個）からは最大でも 3 個
- 暴走には 2 つがそろう必要がある: ①この 1 個の「入口」、②セロトニンと誤判定された触角葉の 40 個（左右に 20 個ずつ）による増幅。どちらか一方を除けば暴走は消える。増幅器は左右両方にあるので、右だけ暴走する理由は右の入口
- シナプス不足だけでは暴走しない: 公開版で左の砂糖 GRN の出力を 90% まで削っても、活動は最大 418 個
- Shiu らが選んだ右の砂糖ニューロン 9 個（LB3c と LB4b、この 1 個を含まない）では、150 Hz 以上で MN9 が動き（150 Hz で 29 Hz、左の組は 66 Hz）、暴走しない → 失敗はどのニューロンを刺激するかにも左右される
- 全補正後も、右の砂糖刺激は左より多くのニューロンを動かす（1,044 対 429）。読み出し補正では MN9 の入力も ×1.06 した

### 数値の修正
- 砂糖 GRN の出力シナプス総数: 左 8,800（正確には 8,759）、右 3,000（3,005）
- Brian 2 との一致: r ≥ 0.999（0.9995〜0.9999）、409〜8,856 ニューロン。Brian 2 の右の暴走は刺激ニューロンを除いて 8,742 個、MN9 0.55 Hz
- 版の比較: ID が変わらなかった 362 個で r = 0.997（刺激した 20 個を含む）。MN9 は v783 で 12% 低い

### 図 3（誤りの用量反応）の改訂値 — JO→aDN1 を追加、抑制は砂糖が 20 Hz 超のときだけ評価
- シナプスの見逃し（脳全体で一様）: 効果が半分になるのは aDN1 14%、砂糖 MN9 21%、aBN1 45%。30% で MN9 は 8%、40% でゼロ。まとめると「多くの予測は 14〜24% の見逃しで半減」
- 苦味・Ir94e の抑制は、砂糖の応答が残っている間は保たれる（それ以降は評価不能）。以前の「抑制は 33〜45% まで耐える」は見かけの効果だったので撤回
- ランダムな符号の誤り: 1〜2% で平均の変化は 15% 以内（ただし 1 回ごとには最大 50% ずれる）。8〜18% で 5 つ中 4 つの予測が半減。20% で 3 回中 2 回暴走
- AI の確信度に基づく誤判定: 0.25 倍で伝達物質が 8.2%、符号が 6.1% の細胞で変わる（AI の実際の誤り率約 6% と同程度）。3 回中 2 回はすべての予測が 20% 以内、残る 1 回は暴走し aDN1 をほぼ失う。平均ではランダムな誤りより悪くはないが、暴走は起きやすい（同程度のランダム 5% では暴走 0 回）
- 強さのばらつき: σ = 0.25 でおおむね保たれる（aDN1 −25%）、σ = 0.5 で aDN1 −56% かつ 3 回中 1 回暴走、σ = 1 で全回暴走
- 5 シナプス未満を捨てる: aDN1 −83%、aBN1 −46%

### 図 4（131 タイプ）の改訂値 — 暴走の判定から刺激したニューロン自身を除いた
- 暴走したタイプ: 公開版 60/131（46%、嗅覚 53 中 52）→ 触角葉補正 8（6%、すべて嗅覚）→ さらに細胞タイプ単位の符号補正 1（光受容細胞 R1–6。片側 4,029〜4,423 個を刺激し、視葉を広く動かす自然な応答と考えられる）
- 左右の一致度（暴走したタイプを除く、n = 118）: 同じ側の繰り返し 中央値 r = 0.99、左と右 r = 0.58（四分位 0.43〜0.72）、P = 4 × 10⁻²¹。118 中 85 で繰り返しの最低値より低い
- 食い違いは、刺激したタイプ自身のシナプス数の左右差（ρ = −0.01、P = 0.9）とも、伝達物質の符号の左右差（ρ = −0.06、P = 0.5）とも関係しない。符号を細胞タイプ単位でそろえても少ししか改善しない（0.62 対 0.58、P = 0.01、n = 115）
- 嗅覚: 刺激した側に残る活動の割合 右 0.45 対 左 0.53（P = 0.002、n = 45）。機械感覚: 0.89 対 0.87（P = 0.44、n = 39）
